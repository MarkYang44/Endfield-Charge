# Endfield Charge 1.2.0

See [validation and measurement limits](https://github.com/MarkYang44/Endfield-Charge/blob/v1.2.0/docs/capsule-sharing-validation.md) and the [configuration guide](https://github.com/MarkYang44/Endfield-Charge/blob/v1.2.0/docs/configuration-sharing.md).

## English

- Share capsule configurations through local `.endfield.json` files, with merge/replace previews and one pre-import backup for undo. Shortcuts, language, screen placement and login preferences remain local. Newly imported rules stay disabled.
- Add up to four ordered color conditions per capsule using the existing metric catalog and theme/lime/amber/red palette. Original battery geometry and power animations remain unchanged.
- Create thermal-state and memory-pressure transition rules, with a quiet first baseline, optional hold, cooldown and localized state labels. Severe alerts take priority over ordinary palette conditions.
- Rotate a chosen queue through one transient cycle, or explicitly enable persistent display. Power events retain priority. Hide/resume releases and restores the corresponding sampler demand; wake waits for fresh data.
- All added controls and messages support English and Simplified Chinese. Existing preferences and shortcuts are preserved. Rotation and persistent display remain off by default.

Requires macOS 13+. Universal Apple Silicon/Intel archive; no additional runtime. Ad-hoc signed, not Apple-notarized. Intel/macOS 13 execution has not been tested on physical hardware; both binary slices and deployment targets are checked.

Background state evaluation runs every 30 seconds and can miss brief transitions. Network counters are local observations, not connectivity probes. Sharing uses Endfield Charge's own versioned format; arbitrary Plus JSON imports are not supported.

## 简体中文

- 通过本地 `.endfield.json` 文件分享胶囊配置，支持合并/替换预览和一份导入前备份，可撤销上次导入。快捷键、语言、屏幕位置与登录偏好留在本机；新增导入规则默认停用。
- 每个胶囊可设置最多 4 条有序配色条件，使用已有指标与主题/黄绿/琥珀/红色色板。保留原电池布局及电源动画。
- 新增系统热状态与内存压力变化规则，支持安静基线、保持时间、冷却与双语状态文字。严重提醒优先于普通配色条件。
- 支持短暂展示时轮播一轮队列，或显式开启常驻。电源事件优先；隐藏/恢复会释放/恢复对应采样需求，唤醒先等待新数据。
- 新增控件和提示支持中英文，保留原偏好及快捷键。轮播和常驻默认关闭。

需要 macOS 13 及以上，发布包含 Apple Silicon/Intel 双架构，无额外运行时。采用 ad-hoc 签名，未经 Apple 公证；尚未在 Intel/macOS 13 实体机器运行验证，已检查双架构及最低系统版本。

后台状态评估每 30 秒一次，可能错过短暂变化。网络计数是本地观测，不主动探测连通性。配置使用本软件的版本化格式，不支持任意 Plus JSON 文件。
