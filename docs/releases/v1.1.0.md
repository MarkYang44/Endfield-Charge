## English

Endfield Charge 1.1.0 adds local NETWORK and STORAGE telemetry, editable capsule profiles, and optional threshold alerts while preserving the original Endfield artwork, palette and three-stage animation.

- **Network:** upload/download rates, observed-session counters and enabled `en*` interfaces. First/reset/unavailable rates remain unknown; LAN traffic is included.
- **Storage:** APFS Data volume total, used, free and user-available space, with shared-container accounting.
- **Capsules:** edit titles, primary/secondary metrics and ring scales; preview the active profile from the menu or your existing shortcut.
- **Rules:** disabled by default, with strict thresholds, hold times, cooldowns and recovery before rearming. No startup replay.
- **Languages:** Chinese / English / system language throughout functional navigation and controls, with bilingual READMEs and developer guides.
- **Efficiency:** demand-driven network/storage, one bounded serial collector worker, bounded graphs and on-demand UI helpers. No new external runtime.

Upgrades preserve existing settings and shortcuts. Upstream MIT notices for GlacierGlimmer/zmd-charge-plus-for-macos ship with the app.

**Install:** extract `Endfield-Charge-macOS.zip`, then move `Endfield Charge.app` into Applications. Requires macOS 13+; the archive supports Apple Silicon and Intel. Builds use ad-hoc signing and are not Apple-notarized; use the normal macOS Open / Privacy & Security flow if prompted.

## 简体中文

Endfield Charge 1.1.0 新增网络、存储遥测，可编辑胶囊方案与通用阈值提醒，保留原终末地图案、配色和三段动画。

- **网络**：上传／下载速率、观测会话累计与已启用 `en*` 接口；首样本、重置与缺失速率显示未知，包含局域网流量。
- **存储**：区分 APFS Data 卷总量、占用、空闲与用户可用空间，反映共享容器口径。
- **胶囊**：编辑标题、主副指标和圆环上限，菜单或原有快捷键预览当前方案。
- **规则**：默认关闭，支持严格阈值、持续时间、冷却及恢复后重触发，启动时不补发历史提醒。
- **双语**：功能导航和控件支持中文／English／跟随系统，README 与开发指南提供独立双语入口。
- **轻量化**：网络／存储按需采集，单个有界串行后台队列、有限曲线历史及按需界面进程，无新增外部运行时。

升级保留原有设置与快捷键；参考 GlacierGlimmer/zmd-charge-plus-for-macos 的相关版权与 MIT 文本随包保留。

**安装**：解压 `Endfield-Charge-macOS.zip`，将 `Endfield Charge.app` 放入 Applications。需要 macOS 13+，同时支持 Apple Silicon 与 Intel。应用使用 ad-hoc 签名，尚未经过 Apple 公证；如系统提示，请通过正常“打开”或“隐私与安全性”流程确认。
