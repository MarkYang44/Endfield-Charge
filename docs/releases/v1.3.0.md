# Endfield Charge 1.3.0

- Opt in to Codex 5-hour or weekly remaining quota from Select Capsule, with a reset countdown and official OpenAI ring mark. Uses an installed, signed-in local Codex CLI; unavailable data stays unknown.
- Bounded asynchronous account reads reuse a small memory cache and never block system telemetry. Existing battery animation, five default capsules, preferences and profile capacity are preserved.
- Includes the prior ownership, source organization and focused verification improvements. macOS 13+, universal Apple Silicon/Intel, ad-hoc signing.
