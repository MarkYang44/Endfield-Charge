# Endfield Charge 1.3.1

- Settings and the Telemetry Terminal now respond to standard keys: Command-C/V/X/A/Z in fields, Command-W/M, and Command-1–7 (Telemetry 1–5) to switch sections. The menu bar menu shows the active global shortcut beside Preview Selected Capsule.
- Clearer settings: shortcut modifiers appear as lime key caps, the header shows the open section, and one footer line confirms auto-save or explains invalid input in orange, wherever the field is scrolled. On Capsules, the footer previews the edited capsule from any scroll position.
- Less hunting: Display fits without scrolling, Display and Capsules link to each other's persistent and playback settings, and blank rows are gone. Sharing & Import also accepts a dropped `.endfield.json`, using the same preview and confirmation.
- The persistent carousel swap fades and settles at 96% instead of shrinking to nothing. Reduce Motion still switches directly. The battery HUD, its three-stage animation, colors and existing preferences are unchanged. macOS 13+, universal Apple Silicon/Intel, ad-hoc signing.

中文：设置和遥测窗口支持标准快捷键：输入框可用 Command-C/V/X/A/Z，Command-W/M 关闭和最小化，Command-1–7（遥测 1–5）切换分区；菜单栏菜单在“预览当前胶囊”旁显示当前全局快捷键。快捷键修饰键改为黄绿键帽；页头显示当前分区；底栏统一显示“自动保存”状态，输入无效时用橙色说明。胶囊页底栏可直接预览正在编辑的胶囊。显示页无需滚动即可看全，与胶囊页可互相跳转到常驻和播放队列设置；分享与导入窗口支持拖入 `.endfield.json`，仍需预览并确认。常驻轮播切换改为淡出并收至 96%，不再缩小到零；开启“减少动态效果”时仍直接切换。原电量 HUD 的图案、三段动画、配色和已有偏好保持不变。
